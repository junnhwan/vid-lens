把重复操作变成可复用流程

B站 · 35:42 · 示例视频

内容导图

适用场景

日常里有些操作会反复出现：整理表格、发出同一类通知、把文件按规则归类。视频把这件事收成一条主线：与其每次重做，不如把步骤存成一套可以再次运行的流程。

说话人演示的是一个叫「自动化流程」的界面。左侧是流程中心，中间是当前流程。这一段没有比较不同产品，只说明重复操作为什么值得被保存。

配置步骤

配置从菜单开始。 时界面还停在编辑状态，主按钮是「添加步骤」。到 ，菜单展开，能看到「添加步骤」「保存流程」和「运行」。

保存之后，这套步骤可以再被运行。视频里的顺序是先打开菜单，再选择保存流程，然后才运行。

补充解释

先保存，是为了让当前步骤成为一份可复用的配置。如果跳过保存直接运行，流程还没有被记录，下次仍要重做。原视频没有单独演示失败画面，这段只补充理解顺序所需要的原因。

注意事项

菜单里的名称以画面为准：「保存流程」不等于已经运行。05:12 和 05:24 只覆盖菜单展开前后，没有看到运行完成后的结果页。文章因此不描述运行之后的界面。
