# 作者免费 AI 服务

登录后，设置 → AI 配置中可一键启用作者提供的免费服务。原有自备配置保留；把自备配置重新设为默认即可切换。免费渠道可能限流、调整或暂停，不保证可用性。

## 管理

在服务器 `.env` 中设置 `VIDLENS_HOSTED_AI_OWNER_ID` 为作者的用户 ID，重启后生效。未设置时管理入口关闭。权限按数据库中的指定账号校验，不依赖客户端隐藏按钮，也不会赋予账号其他管理权限。演示账号和已删除账号不能管理。

作者登录后进入设置 → AI 配置 → 管理免费服务，配置对话、视觉、ASR、Embedding、Reranker 五项服务。对话、视觉、ASR 填 API 基础地址；Embedding 和 Reranker 填完整接口路径。密钥留空保持原值。取消“开放免费服务”并保存即可暂停。

配置以加密单例保存于 PostgreSQL，沿用 `security.api_key_secret` 加密器。用户行只保存 `source=hosted` 的选择，不复制凭据。新请求/后台任务解析时读取最新配置，不需重新部署；已经执行中的请求可能沿用开始时的配置。暂停后新的解析失败，不会回退消耗其他服务端凭据。

普通用户接口只返回模型等能力描述，地址、Provider 和密钥字段为空；作者接口也不返回原密钥。免费配置禁止编辑、删除、导出和复用密钥进行自定义地址探测。重排序使用免费配置的模型、地址及凭据，优先于全局确定性重排序设置。

Embedding 维度必须与服务器当前检索表一致。更换 Embedding 模型可能需要重建已有视频索引；保存配置不自动触发重索引。更新部署时保留 `.env`、加密密钥、数据库及媒体数据。

## 视频链接导入开关

部署环境可在 `.env` 中设置 `VIDLENS_DISABLE_URL_IMPORT=true`，重启后端后生效。`GET /api/v1/media/import-options` 返回当前状态，上传窗口将“视频链接”置灰并提示“暂未开放”；`POST /api/v1/media/upload-url` 同时返回 403，防止绕过页面调用。该开关不影响本地文件上传。未设置环境变量时使用 `upload.disable_url_import`，两者均未设置时允许链接导入。
