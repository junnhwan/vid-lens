# 映知 VidLens 整体界面重构方案

日期：2026-10-10  
状态：设计方案。本轮不改业务代码。  
范围：桌面 Web，1440px 与 1024px。  
核查：分支 `codex/summary-experience`，HEAD `cee06de`。工作区另有未提交的摘要阅读层调整，方案保留这些修改，不把它们当成已完成的重构。

## 1. 已确认的产品上下文

主线已经从「处理、问答、学习成果并列」转为：

导入视频和可选关注点 → 自动生成可阅读、可回查的摘要 → 按需回放、选段提问、修订、查看章节结构和管理标签。

摘要是主要产出。截图、章节结构、问答和标签分别服务理解、回查和管理。学习笔记仍是另一套数据，不是摘要的别名。

## 2. 核心旅程和当前阻碍

| 旅程 | 用户要完成的事 | 现在被什么挡住 |
|---|---|---|
| 首次导入 | 放入链接或文件，可选写关注点，然后离开 | 关键输入排在说明和高级项后面；提交按钮随内容下移 |
| 等待处理 | 知道进行到哪、能否离开、失败了做什么 | 卡片变成转写分片和并发报告；完成后这些信息消失 |
| 开始阅读 | 先看结论，再看章节 | 生成说明、重试、版本注记和标签操作堆在正文前 |
| 回放核查 | 从章节或图回到画面 | 回放在侧栏，但空问答和多个顶栏按钮把关系弄乱 |
| 选段提问 | 选段后单独输入问题 | 能力已在侧栏，空状态却像另一个产品首页 |
| 修订 | 预览、应用、撤销，并知道当前版本 | 修改入口和「生成原稿」注记混在阅读流里 |
| 再次打开 | 回到上次阅读位置 | 位置按正文摘要保存，这点应保留；首页却不把「继续阅读」放在唯一入口 |
| 跨视频问答 | 在已索引视频中提问并找回会话 | 问答页先选范围，历史不在这页主体 |
| 失败恢复 | 只重试失败的那一段 | 重试、诊断编号和运行报告占据阅读区 |

## 3. 审查

严重程度：高表示挡住主路径；中表示能完成但持续费解；低表示一致性或边缘页。

### 3.1 附件对应的问题

| 位置 | 用户影响 | 级别 | 原因 | 建议 |
|---|---|---|---|---|
| 视频卡片，工作台与视频库共用 `VideoCard` | 封面区重复长文件名；其下在转写阶段展开分片、并发、服务配置和画面帧进度 | 高 | 进度面板被嵌进卡片，且只在处理中渲染 | 封面不再放标题。卡片始终一行状态。详情进「查看进度」 |
| 导入弹窗 | 链接在关注点和高级项之后。5175 上 1024×800 展开高级项后，提交按钮离开视口 | 高 | 整窗滚动，主按钮在内容末尾，分组没有依赖关系 | 来源在上，按钮固定，高级项分组收起 |
| 视频阅读页 | 截图中的活动、补图重试和「生成原稿」出现在概览前；顶栏操作同等大小；标签带保留和删除 | 高 | 运行说明和正文使用同一阅读栏 | 限制收成一行；管理进入弹层 |

截图里的标签管理和折叠导图，对应未提交改动之前的界面。改动后标签默认只剩名称，导图会直接渲染；方案仍要求目录默认可读，并写明它只来自章节标题。

### 3.2 整站另外发现的问题

| 位置 | 用户影响 | 级别 | 建议 |
|---|---|---|---|
| 侧栏「资料 / 学习与产出」 | 六个入口权重相同，摘要没有归属 | 高 | 见第 4 节 |
| 工作台首屏 | 演示账号浅色首屏仍写「整理学习笔记」，下方大片空白 | 中 | 删除独立工作台 |
| 空视频库 | 工具条拥挤，下面再重复四步旅程 | 中 | 空库只留导入和一句说明 |
| 阅读页导图 | 用户找不到，找到后发现只是标题 | 中 | 默认显示章节目录，标题使用「章节目录」 |
| 侧栏空问答 | 大标题和推荐问题占满辅助区 | 中 | 默认回放；问答空状态贴近输入框 |
| 问答入口 | 两张范围卡很大，单视频区在空库时只剩「没有匹配的视频」 | 中 | 会话列表成为主体 |
| 任务页 | 首页「查看任务」进入的是视频处理和学习笔记运行的混合列表 | 中 | 顶栏状态按对象分开 |
| 视频与来源 | 打开后仍以转写、索引、生成摘要、新建笔记为主操作 | 中 | 降为二级视图，返回摘要是唯一返回 |
| 技术页与卡片进度 | 同一套阶段条、转写面板、画面面板重复出现 | 中 | 进度只有一个组件，卡片用摘要句 |
| 浅色与深色 | 首跑英雄区在浅色页里仍是一整块深色插画 | 低 | 空状态改用当前主题的表面 |
| 设置、知识库、检索测试台 | 可用，但标题和卡片密度与阅读页不一致 | 低 | 后一阶段只统一排版 |

共性原因：壳层还在表达旧的并列功能；运行事实直接铺进阅读面；没有唯一主操作；单组件完整，合成整页后便拥挤和空白同时存在。

### 3.3 实看范围

2026-10-10 用演示账号打开 `http://127.0.0.1:5175`：浅色工作台、空视频库、导入弹窗收起与展开、问答入口、成果页加载骨架。1024×800 时展开高级项，提交按钮不在可见区域。

没有再次登录用户截图里的真实视频，因此没有在本轮点击深色阅读页的回放、修订、补图和键盘路径。那些判断来自截图和组件源码。

## 4. 信息架构

推荐侧栏：

1. 视频库
2. 问答
3. 知识库
4. 底部：设置、文档、账号

顶栏保留面包屑和导入。有真实进行中的导入、摘要、补图或笔记时，顶栏增加一条状态，不增加导航项。

### 4.1 对六个问题的结论

工作台和视频库不再分开。分开造成两个视频列表，空状态还各讲一遍旧旅程。视频库首页在有未读完的摘要时，顶部放一条「继续阅读」；有进行中的处理时，放一条真实状态。没有这些状态时直接是筛选和视频。

单视频问答留在阅读页右侧，和回放共用辅助区。放大问答是同一页布局。`/chat/v/:id?session=` 继续可用，打开时进入该视频阅读页并选中同一会话。已有按账号、视频和会话保存的草稿、引用与锚点继续使用。

跨视频问答和会话历史放在「问答」。这页主体是历史，范围选择收成视频库和知识库两个紧凑入口。单视频历史行回到阅读页，不打开另一套聊天壳。

标签是用户词表里的平铺分类，用来筛选全部视频。知识库是显式加入的成员范围，决定检索和问答边界。标签不会把视频加入知识库。S5B 未实现，知识库页不提供标签筛选。

任务不再占用一级导航。视频处理进度留在视频卡片和阅读页。学习笔记运行留在笔记详情。顶栏只汇总「现在有没有还在跑的事」。`/tasks?run=` 保留给笔记运行深链。

成果不再作为一级入口。摘要已经覆盖单视频的阅读、章节、修订和回放。学习笔记仍独立保存版本、证据、候选版本、阅读位置，以及从转写或画面另行整理的内容。这些不是摘要修订。笔记从视频「更多」、旧链接和已有学习位置进入。

保守替代：如果需要一个「接着上次」的首屏，只在视频库顶部保留继续阅读，不恢复工作台。不建议把笔记并回侧栏；那样会重新把两种正文并列。

| 视频库 | 视频库 | `/library` |
| 视频摘要 | 阅读工作区 | `/video/:id` |

| 独立问答 | 阅读页问答 | `/chat/v/:id` 打开阅读页问答 |

### 4.3 切换时保留什么

| 状态 | 规则 |
|---|---|
| 视频库筛选 | 留在 URL |
| 阅读位置 | 继续按账号、视频和正文摘要保存。摘要变化后回到顶部，不沿用旧章节位置 |

| 导入弹窗草稿 | 关闭前提示。上传中的本地文件沿用现有取消规则 |

## 5. 视觉与交互规则

保留映知 / VIDLENS、暖炭与琥珀。浅色主题继续走现有 token，不另做一套色板。精致来自层级、字号、行宽和间距。不新增渐变、大阴影或装饰插画。

### 5.1 字体与阅读

| 用途 | 规则 |
|---|---|
| 界面 | `--font-ui`。页面标题 28/36，区块标题 20/28，正文界面 14/22，辅助 13/20，元信息 12/18 |
| 摘要正文 | `--font-read`。概览 18/32，章节 16/30 |
| 行宽 | 摘要栏最大 68 个汉字，约 720px。1440 宽屏不把正文拉满 |
| 标题 | 视频标题只出现一次。文件名放到来源详情 |
| 等宽 | 只用于时间、版本号和诊断编号 |

### 5.2 间距与表面

间距只用 4、8、12、16、24、32、48。阅读页区块之间 32。卡片内边距 16，卡片之间 16。

页面背景 `--bg-0`，栏 `--bg-1`，悬停 `--bg-2`。分割用 1px `--line`。圆角沿用控件 9、卡片 14、弹窗 18。图标沿用现有 16px 线性图标。封面缺失时用 16:9 的纯色面加来源类型，不再把标题排进封面。

### 5.3 操作与状态色

一页或一窗只有一个主按钮，使用琥珀底和深色文字。其余用描边或文字按钮。破坏性操作只用危险色文字，不做成大色块。

成功、警告、失败、信息只点状态文字或 8px 状态点，不给整张卡片染色。禁用降低对比并去掉指针。焦点使用现有 `--focus-ring`，2px 外环。悬停只改变背景或文字色，不移动布局。

### 5.4 弹窗

弹窗最大高度为视口减去 64px。标题和底部操作固定，中间区域滚动。遮罩点击不关闭含有输入的弹窗；Esc 关闭前若有未提交内容，沿用现有确认。嵌套弹窗先关闭内层。

导入弹窗底部始终是主按钮。本地文件在选中文件前，主按钮说明「选择视频后开始」。

### 5.5 动效

只保留 160ms 的表面颜色变化，以及当前一条活动的呼吸。完成时该条变为静态勾，不推动正文。`prefers-reduced-motion` 下取消呼吸和位移，保留文字与图标。后台刷新不改变阅读栏高度。

## 6. 关键页面

### 6.1 视频库首页

1440：侧栏 224px。内容区上沿是标题和「导入视频」。其下最多两条状态：继续阅读、进行中的处理。再下是一行工具：搜索、状态、标签、卡片或列表。视频使用固定比例卡片。

卡片内容依次为：16:9 画面或紧凑占位、一行标题、一行「可阅读 / 正在整理文字 / 未能生成」加最多三个标签。处理中的卡片不增高。点击卡片进入阅读页；若尚无摘要且未在处理，阅读页给出「生成摘要」。

1024：侧栏改为 72px 图标。工具条允许换到第二行。卡片改为两列。

空库不显示四步旅程。标题下是一句「导入后会生成可阅读的摘要」和主按钮。有筛选而无结果时，只说没有匹配，并提供清除筛选。

列表视图保留给标题很长、需要扫描状态的情况。列是标题、状态、标签、更新时间。

### 6.2 导入

顺序固定：

1. 本地文件或视频链接。链接导入不可用时，链接页显示原因，不禁用到无法理解。
2. 来源字段。链接页是输入框和分 P 说明。文件页是拖放区，选中后显示文件名和大小。
3. 关注点，单行，可空。只有「导入后自动生成摘要」开启时可填。
4. 收起的三组：文字、画面、整理。
5. 固定主按钮：「导入并生成摘要」或「仅导入视频」。

文字组：链接可选「优先平台字幕」或「直接转写」，以及语言。本地文件固定为转写，不显示平台字幕选项。

画面组：允许查看必要画面。关闭后，摘要形式只剩文字。形式默认自动。

整理组：章节目录、自动标签。关闭自动摘要后，这两组和关注点禁用，并说明导入后可在视频里再生成。

错误显示在来源字段下。提交后关闭弹窗，视频库新卡片出现在继续项下方，状态使用受理结果，不先显示 100%。

### 6.3 阅读工作区

顶栏：标题、主按钮「提问」、更多。更多里放放大阅读、放大问答、收起辅助区、修改摘要、重新生成、视频与来源、下载、加入知识库。

限制只在改变阅读方式时占一行，例如「文字已可阅读，画面没有补充」。点击才展开活动和重试。版本冲突仍使用现有选择：保留修订或改用新原稿，这是少数允许打断阅读的横幅。

正文顺序：概览、标签名称、章节目录、章节和图。目录默认展开到章节级，节点回到正文。完整图在弹层里查看。目录标题写「章节目录」，说明结构来自当前章节标题。

辅助区默认回放。问答打开后，空状态只保留输入框和最多三条建议，不再使用大标题和品牌标。引用卡留在输入框上，选择不自动发送。

1024：辅助区默认收起。提问或回放按钮打开它，打开时盖住内容区的右侧而不是把正文压到不可读。放大阅读隐藏辅助区；放大问答隐藏正文。两者互斥，Esc 先关内层弹窗，再恢复布局。

技术视图保留转写、画面证据、索引、来源刷新和重新转写。它不是打开视频后的第一屏。返回按钮回到摘要，并恢复离开前的滚动位置。

### 6.4 问答、知识库、笔记和设置

问答页顶部两个文字入口：问视频库、问知识库。下面是会话列表，显示范围、标题和时间。空列表说明要先有已索引视频或知识库成员。

知识库继续管理成员和范围问答。检索测试台留在知识库的更多里。

学习笔记列表不再出现在首页和侧栏。视频更多中的「学习笔记」打开过滤到该视频的列表。笔记阅读页保持现有版本和证据，不改成摘要页。

设置保持外观、AI、记忆和提示词。本阶段只把标题和分组间距对齐第 5 节，不重做表单。

## 7. 状态、跳转和上下文

| 状态 | 呈现 | 不做什么 |
|---|---|---|
| 空库 | 导入 | 不展示旅程插画 |
| 排队或处理 | 卡片和顶栏使用最后一条真实活动 | 不预排后续步骤，不用假百分比 |
| 文字已可读、画面仍在处理 | 阅读入口稳定，行内说明仍在补画面 | 不把新活动插进正文造成跳动 |
| 完成 | 同一位置改为「可阅读」 | 不把进度区直接删掉留一个空洞 |
| 补图失败或无画面收益 | 正文保留，一行说明原因和是否可重试 | 不把文字结果标成图文完成 |
| 缺少模型或转写配置 | 只禁用被挡住的动作，并链到设置 | 不阻止已有正文 |
| 来源不可用 | 正文仍可阅读；回放按钮说明当前不能定位 | 不显示假时间 |
| 断线 | 保留最后活动和已收到文字，提示正在恢复 | 不把服务端任务改成失败 |
| 修订待应用 | 差异留在修订区，正文仍是当前版本 | 预览就绪后停止进行中动效 |
| 只读账号 | 阅读和回放可用，导入、修订、标签修改禁用并说明 | 不隐藏内容 |
| 历史摘要 | 按现有有效版本阅读 | 打开页面不触发迁移或重新生成 |

跳转：

- 导入受理后留在视频库，新项可打开阅读页。
- 从会话打开单视频问题时，进入 `/video/:id?pane=chat&session=`。
- 从阅读页打开笔记时，笔记页提供返回该视频。
- 浏览器后退按 URL 返回上一视图。刷新按 URL 恢复筛选、视图和会话，阅读位置按正文摘要恢复。

## 8. 分阶段实施

| 阶段 | 改造 | 接口 | 验收 |
|---|---|---|---|
| 1 | 侧栏、视频库首页、卡片一句状态 | 现有列表、标签筛选、任务与摘要状态 | 空库、长标题、处理中、完成后位置稳定 |
| 2 | 阅读层级、章节目录、标签阅读态、辅助区 | 现有摘要文档、活动、修订、引用版本 | 1440/1024，正文先于操作；引用版本不匹配时不跳 |
| 3 | 导入顺序、分组、固定提交 | 现有导入选项 | 链接与本地文件两种；800px 高度能看见主按钮 |
| 4 | 问答历史，单视频会话回到阅读页 | 现有会话和跨路由草稿 | 草稿、引用、播放时间在切换后还在 |
| 5 | 顶栏进行中状态，笔记移出侧栏 | 视频任务和笔记运行继续分开读取 | 旧笔记链接和阅读位置仍可打开 |
| 6 | 可交互原型，再改生产界面 | 原型使用标注过的模拟数据 | 实际检查阅读、主操作、弹窗、状态、跳转和键盘 |

阶段 6 的原型不是本文件的替代。模拟活动不能写成真实 Agent。生产实现不移植原型计时器。

本方案没有需要另做选择才能继续的产品分叉。学习笔记降级后路由仍在；若之后希望它回到侧栏，只影响第 5 阶段，不影响阅读页和导入。

## 9. 验收口径

完成不等于页面能打开，也不等于旧入口都还在。桌面验收要看到：

- 1440 和 1024 下，摘要一行宽度可读，主按钮在视口内。
- 导入弹窗在高级项展开后仍能提交。
- 处理从等待到完成，卡片和阅读页骨架不跳动。
- 从库到阅读、从会话回到阅读、后退和刷新，筛选、草稿、引用版本和播放时间符合第 4.3 节。
- 键盘可以到达目录、回放、提问和关闭弹窗。
- 只读、失败、无封面、长标题、多标签和空会话都有确定的样子。
