# Agent 引用与视觉证据

Agent 的事实来源是当前用户授权视频中的转写、OCR、画面描述和带来源的视觉观察。引用保留 EvidenceID、视频、模态、来源与真实时间范围，时间未知时保持 unknown，不能从 chunk index 推算时间。

`search_transcript` 限定转写及其时间状态，视觉检索走独立工具。`get_transcript_window` 将窗口内邻居的完整来源加入本轮证据池，仍接受相同的归属和引用校验。

视频地图复用摘要与持久 timeline，提供有界标题、可用模态、跨全片的抽样定位点及源内容版本。长文本均匀抽样保留尾部，未知时间维持原顺序；没有持久测量时长时返回未知。地图用于指导检索，不进入引用池，也不能把抽样描述成已检查所有内容。

知识库多轮从 PG 保留来源完整且仍属于当前成员的问答对；快照来源与规范化来源不一致时整对不入模。启动冻结成员集合，工具执行、入池和发布时复查，普通 Chat 保存也在事务中校验完整初始集合。比较回答按视频保留已观察的相关证据，并明确缺证一侧，不能以无关片段凑覆盖。

最终回答工具参数中的引用只是选择器。服务端按本轮已观察证据替换其正文与来源，并在 observation 边界再次 canonicalize。未观察、跨视频或伪造来源的引用不能进入最终生成。工具参数不能传入可信 memory context；记忆不是引用证据。

`search_visual_evidence` 检索已有 OCR/描述，`inspect_visual_window` 读取已存储窗口；只有 `investigate_visual` 会按已知 seed windows 下载视频、抽帧并调用 VLM。观察仍可能不充分或相互冲突，不代表事实已经被独立证明。`video_visual_observations`、帧存储及对象清理保持独立。

当前回答以本轮已观察、已通过作用域和引用校验的 evidence 为依据。基础引用、EvidenceDrawer 和播放器时间跳转使用聊天快照与源证据；视觉观察单独保存，时间和模态信息随 citation/source refs 返回。

转写重试检查点保存完整音频窗口及可选的原生 ASR 段落时间。Whisper 兼容模型请求 `verbose_json` 段落时间；其他模型保留默认协议。原生段落时间经过窗口边界校验后转换为视频绝对毫秒；无效、重复而无法唯一对应、或与原文不一致的段落保留粗定位。逐词时间暂不作为句子引用，避免单词被单独列为证据。音频核心窗口为 20 秒，两侧各最多 2 秒，纯文字模型也可回溯到不超过 24 秒的真实窗口；相较旧 300 秒核心段，请求数增加约 15 倍，音频重叠也增加。

检索可以合并多个来源，但写作使用单独的句子引用表，不沿用整个检索块的联合时间。Agent 的有界收尾保留完整 anchor，确保 writer 和 observer 的编号一致。回答来源卡、知识库证据和引用抽屉按视频、模态、时间状态及相同毫秒范围合并展示来源片段；同组的多个 Cn 保留各自原文、关联结论与支持状态，可分别选中高亮。来源组数量与引用句子数量分开显示，一组只提供一个回放入口。未知、无效或不能确定所属视频的来源不因零时间合并。转写时间轴的阅读段落保留在原来源时间下，不再为每个阅读段落重复时间与回放入口。

粗粒度来源不超过30秒时显示“约定位”，更长的旧来源显示“原片段”；两者均不代表句子级或逐字精度。旧视频可在转写页按需“补齐引用定位”，通过现有强制转写队列更新转写及检索索引，可能再次产生 ASR 和索引费用；未完成时使用续跑入口保留已完成分片，历史回答保留原快照。旧 v3/source-map-v2 检索仍可用，单独重建向量不能补出缺失的语音时间。

后台 ASR 在本地模型额度不足时按实际 RetryAfter 等待，单次本地等待上限一分钟，并响应任务取消；该等待不代表额外语音服务调用。共享 provider retry 额度仅在本地限流放行后消耗，正常分片的首个请求不消耗重试额度。真实供应方失败仍受既有重试次数与任务预算约束。

发布与幂等见 [Agent 执行](agent-evolution.md)，事件与最终文本覆盖规则见 [SSE 契约](agent-streaming-contract.md)。

无句子时间的转写时间轴与引用均使用完整音频窗口，不能以处理用 core 区间截短包含重叠语音的文本时间。core 仅负责处理归属；有 native timed segments 时继续使用已验证的语音段时间。

引用显示编号按每条回答正文首次出现顺序连续分配（C1…Cn），同一引用再次出现时复用显示编号。正文、来源卡、证据抽屉、跨视频来源栏与复制回答共享同一映射；来源分组不重新分配句子编号。旧候选编号保存在前端 candidateId 及原有后端引用快照中，技术详情可追溯。该映射仅为显示投影，不改写持久化回答、来源原文、时间范围或支持状态，也不改变按 message_id 导入笔记的原始快照。无行内链接的旧快照按原顺序补充显示编号；代码与链接内的编号示例不参与编号。
