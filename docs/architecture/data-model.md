# 数据模型与存储边界

## 持久化事实

PostgreSQL 是主要关系数据源，负责保存用户、资产、视频任务、任务阶段、转写、摘要、知识库、聊天会话以及 AI 调用和配额记录。

任务和各处理阶段分别记录状态，使下载、转写、摘要和 RAG 索引能够独立重试，并能在故障后继续处理已完成的部分。

## 检索数据

转写内容按检索粒度写入视频分块。分块记录是 RAG 内容的主要事实来源；向量表和其他向量后端属于可重建投影，用于加速相似度检索和对账。

数据库关系图见 [database-schema.svg](database-schema.svg)。对应的模型定义位于 [`internal/model/`](../../internal/model/)，向量适配器位于 [`internal/vector/`](../../internal/vector/)。

## 外部存储和协调组件

- MinIO：视频、音频和其他大对象
- RabbitMQ：异步任务投递、消费和重试
- Redis：缓存、短期锁和配额辅助状态
- PostgreSQL：业务状态、转写内容、聊天记录、检索事实和审计数据

外部对象和投影清理必须具备幂等性；数据库中的任务状态负责记录清理意图和最终处理结果。
