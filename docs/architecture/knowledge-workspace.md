# 知识库工作区

## 当前能力

1. 集合检索：在授权成员集合上计算 BM25 语料统计，与向量召回进行 RRF 融合，并保留视频、模态、时间和来源标识。
2. 知识库 Agent：复用有界 Planner/Tool/Observe 循环，检索工具可覆盖集合或指定成员，窗口工具必须选择授权视频。
3. 产品工作区：提供问答、按视频分组的证据、运行轨迹和回放入口；加载、空结果、取消、失败和预算耗尽均展示真实状态。
4. 检索测试台：使用原始问题调用真实检索管线，支持向量、关键词和混合模式，展示各通道、融合候选、最终排序、降级与耗时；不调用最终答案模型，不保存测试问题。
5. 运行详情：读取 owner-scoped 执行记录，展示状态、步骤、耗时、预算与用量来源；不返回私密规划草稿、密钥和完整内部检查点。
6. 长期记忆：通过 PostgreSQL 持久任务完成偏好抽取、幂等处理、租约恢复和有限重试；写入前检查用户、会话和作用域授权。

## 界面结构

知识库页面使用资料卡片展示成员视频，证据按时间片段和视频分组呈现。日常问答优先展示问题、依据和回放入口；检索测试台和运行详情提供诊断信息。

## 运行边界

服务端通过模型迁移创建记忆任务表。记忆受 `memory.enabled`、用户默认值和会话策略共同控制；自动抽取只处理明确表达的回答偏好，不把视频内容写成个人记忆。

知识库 Agent 在 Run 创建时冻结 `member_task_ids`，并在规划、工具执行和最终保存边界校验成员范围、视频归属和索引就绪状态。知识库会话消息用于展示，模型上下文按当前授权成员集合加载。

真实模型质量与大规模集合延迟使用本地私有评测数据衡量，不将检索候选分数表述为事实可信度。当前 BM25 在授权集合上由应用进程计算语料统计，大集合吞吐需通过真实数据压测评估。

## 验证范围

测试覆盖权限隔离、跨视频证据、成员集合变化、记忆任务重试、撤回、检索模式和回放链接。浏览器夹具用于验证界面交互；真实模型质量以独立评测数据衡量。
