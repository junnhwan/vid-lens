# 从一条视频开始

## 适合什么视频

建议先选技术讲解、科普、课程学习、操作教程或有清晰讲述的知识分享。讲述有主线、字幕或转写能传达主要内容、画面能补充解释时，更适合转为图文。字幕不完整或识别不准时，请结合引用回看原片。

音乐、风景、纯剪辑等缺少讲述的视频，可整理的信息较少。舞蹈、比赛集锦或剧情片段中的连续动作、节奏与观看体验，也难靠少量静态画面完整表达。选片建议不限制题材，但文章不能替代这些视频的观看体验。

## 提交链接

在首页粘贴链接，选择可用模型，点击“开始解读”。B 站链接支持指定一个分 P；YouTube 支持单条视频。来源不可访问、过长或超过容量限制时会显示原因。

首页“视频工作区”显示本站为视频与处理素材设置的专用配额和剩余空间。正在处理的任务会预留工作空间；容量不足时会暂停接收新下载，请在可用空间恢复后再尝试。

“添加关注点”是可选输入。留空也能开始；它不会变成必须完成的向导。

## 等待与恢复

页面按真实活动显示来源准备、文字与画面取证、模型响应和正式核对。只有具备真实窗口进展的转写过程才显示比例，其他工作不会用倒计时制造完成进度。

当前执行计划显示取证、提纲、写作和核对等状态；章节保存后会标记完成。计划随已接受的证据和内容调整，不代表尚未执行的动作已经成功。

每次模型调用有独立序号和记录，同一次调用等待或接收响应时会更新当前动作。实际发送次数单独统计：一次调用遇到连接故障可能发送多次，工具执行和观察保存也会有各自的记录。展开“全部过程”可以回看；页面折叠旧记录不会删除它们。

调查达到相应档位的收尾条件后，系统会优先完成主要内容与核对，把未确认的部分写入限制说明。必要的证据和引用校验仍需通过，因此不保证固定分钟数完成。

较长视频可能需要几分钟，也可能更久。网络断开后页面会尝试读取已有资源；不要因为画面暂时没有变化就连续新建相同任务。刷新当前地址可以恢复已保存的结果与过程。

## 停止或重试

停止会解除本次请求的需求。其他访客仍需使用的共享素材准备不会被连带取消。失败后若允许重试，原关注点、解读深度与模型继续适用；来源、配置和协议兼容且所需素材可用时，会接续已保存章节与观察。否则会从可用来源重新处理。更换关注点或模型请开始新的解读。

## 结果就绪

文章在正式核对完成后一次发布。问答会新增私人答案，不修改正文。请留意文章的“还没确认的部分”，并按引用回看原片。
