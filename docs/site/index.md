# 视频的另一种读法

VidLens 沿着原视频的文字与真实画面，将一条视频整理为可独立阅读的中文图文。读完可以围绕当前视频继续提问，回看出处，也可以下载文章。

## 从观看到阅读

粘贴 B 站单个分 P 或 YouTube 单条视频链接。系统先准备来源，再结合完整文字与分布于全片的画面建立概览，按需要回读原文、查看或裁剪真实画面，最后核对引用并发布文章。

文章不是逐句字幕，也不保证替代观看。稀疏画面不能证明所有视觉事件都已被看到；证据不足、声音转写精度与图文冲突都可能限制结论。

## 可以从这里开始

- [开始使用](/docs/start)：提交链接、理解等待与恢复。
- [关注点与模型](/docs/models)：让文章更贴近问题，并了解模型固定规则。
- [图文、出处与问答](/docs/evidence)：查证来源，围绕文章继续追问。
- [下载与离线阅读](/docs/export)：选择单个 Markdown 或完整图文 ZIP。
- [查看真实示例](/example)：阅读已选中公开展示的真实图文，并查看保存下来的问答。打开示例不会创建新的模型任务。

## 适用范围

更适合技术讲解、科普、课程与教程，以及有清晰讲述的知识分享。字幕或转写承载主要信息、画面解释概念或步骤的视频，更容易整理成有出处的文章。

音乐、风景、纯剪辑等缺少讲述的视频，可整理的信息较少；依赖连续动作、节奏或剧情体验的内容，稀疏取帧也难以完整呈现。可以按需要尝试，结果仍受原片信息与可用证据限制。详见[选片建议](/docs/start#适合什么视频)。

VidLens 面向桌面浏览器。访客无需注册，文章与问答仍由当前匿名会话持有。请在原视频许可和合理使用范围内使用生成的内容。
