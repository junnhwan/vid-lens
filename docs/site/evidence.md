# 图文与出处

## 阅读真实画面

配图来自原视频的实际图像，不是按文案生成的插画。点击图片可放大，再选择“问这张图”。文章只声称已经取得且观察过的证据；抽帧成功不等于某个结论已经确认。

## 时间与文字引用

正文时间标记用于平台字幕片段和真实视频画面。音频转写保留文字出处，显示“视频原文”，不展示时间点或时间段；点击可打开原视频。

文字引述应为连续原文，概括与补充解释有各自身份。文字和画面不一致时，请结合限制说明判断。

同一段有多处来源时，标记显示首个时间和来源数量；这些来源是独立片段，不能把首尾时间理解成一段连续证据。

## 继续问这条视频

问答侧栏可以从整篇文章、一个选段或一张图继续提问。问答只处理当前视频，不把上一轮答案当作原片证据。证据不足或超出范围时会如实说明。

同一条视频可以保留多个会话。点“＋ 新会话”开始独立话题，点“历史会话”切回已有问答。各会话只带入自己的历史，仍共享当前视频与已发布图文作为阅读范围。列表用首个问题作为标题，显示轮数、创建时间与回答中的状态。

切换时保留各自尚未发送的草稿，刷新后恢复最近选中的会话。切换不会停止另一会话正在进行的回答；回到该会话可继续查看。新建空会话不会调用模型。历史属于当前匿名浏览器，换浏览器、无痕窗口或清除会话 Cookie 后无法直接访问原历史；示例视频的提问次数在各会话之间累计。

新回答的“回答依据”可展开查看实际引用的字幕或转写原文，再打开原视频核对。它也会注明本轮是否查看了画面；已查看的画面可放大。旁白介绍图表、文章中已有配图，都不等于这一轮问答看过图片。旧回答若没有这份记录，不会补写看图状态。

点击发送后，问题会立即进入对话并显示“正在发送”；服务端接收后才开始显示回答过程。发送未确认时会保留问题，便于恢复编辑；你在等待期间新写的草稿也会保留。

回答过程展示实际读取来源、查看画面和核验结果。普通单次模型发送的耗时与用量直接放在主步骤中；重发或失败时才展开“发送详情”。这里不展示模型的私密思考内容。重新回答提交期间会禁用重复操作；对话有更新时会自动同步最新一轮。

等待时会显示当前正在分析问题还是核对回答依据，并区分等待模型响应、模型思考中和接收响应。只有实际收到思考活动时才显示相应状态；没有新活动时会注明最近一次活动距今多久。本轮等待时间会持续更新。复杂问题可以等待更久，仍有等待上限；达到时限不等于模型没有思考，也不代表答案已通过核对。

点击“停止回答”可结束当前问答。按钮会先显示“正在停止”，后台确认后显示“已停止”，此后可继续提问。等待期间写下的新草稿会保留；收起侧栏或切换会话仍会让后台继续处理。

## 可选网络补充

问答区的网络补充默认关闭，是否可用以当前服务为准。每轮主动允许后，可以读取你提供的公开网页，并在搜索可用时查找补充来源。答案会区分视频内容与网页资料。

搜索结果摘要只是候选；只有实际读取的网页快照才能作为引用。无法读取、额度用完或来源不明确时，问答仍可基于视频证据继续。网络补充不会改写文章。
