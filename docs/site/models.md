# 让解读贴近你的问题

## 可选关注点

展开首页的“添加关注点”，用最多 500 字说明这次想了解的内容。例如：重点整理操作步骤、适用条件与容易忽略的细节。

关注点会影响取证深度和文章重点，但不会允许跳过全片概览或编造视频没有的事实。自定义关注点的文章按匿名会话隔离，来源素材仍可以合理复用。

## 选择模型

首页列出当前可供使用的模型，可用列表可能随服务状态变化。模型名和品牌标识用于辨认模型，不代表中转通道是该品牌的官方服务。

同一款模型在首页只显示一次。页面会预选一款可用模型，你可以在提交前更换。

提交后，本次图文、重试与后续问答使用同一型号。某条线路故障时，系统会自动尝试该型号的其他可用线路，保留已有处理进度。音频转写由独立的基础设施处理，不属于这个选择器。

## 模型暂不可用

当该型号的线路都不可用时，新问题会提示原模型暂不可用，并保留草稿；已有文章与下载仍可使用。系统不会自动换成另一型号回答。

默认选项变化只影响新解读。已有解读的问答继续使用原型号；没有可用线路时，需要等待该型号恢复。
