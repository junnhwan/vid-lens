# 让解读贴近你的问题

## 可选关注点

展开首页的“添加关注点”，用最多 500 字说明这次想了解的内容。例如：重点整理操作步骤、适用条件与容易忽略的细节。

关注点会影响取证深度和文章重点，但不会允许跳过全片概览或编造视频没有的事实。自定义关注点的文章按匿名会话隔离，来源素材仍可以合理复用。

## 选择模型

模型由站长提供。首页仅列出可供使用的模型，站长可以调整默认项或停用模型。模型名和品牌标识用于辨认模型，不代表中转通道是该品牌的官方服务。

供应商和模型均已启用、且当前配置通过能力检查后，模型就会出现在首页，无需先设为默认。默认只决定初始选中哪款；未设置默认或默认暂不可用时，页面预选列表中的第一款可用模型。

提交时会冻结所选修订：本次图文、重试与后续问答使用同一模型。音频转写由独立的基础设施处理，不属于这个选择器。

## 模型暂不可用

服务可能临时故障，也可能由站长停用。文章与下载仍可使用；新问题会提示原模型暂不可用，并保留草稿。系统不会自动换成另一模型回答。

站长更换默认模型只影响新请求；密钥轮换或撤销可能使旧修订暂时无法继续问答。
