# 留下一份可以再读的文章

## Markdown

下载单个 Markdown 文件可以保存正文、结构、图注、引用、限制与原视频链接。由于文章配图归匿名会话持有，这个文件使用图注与原视频时间链接，不嵌入需要 Cookie 的图片地址。

导出的思维导图保留主题与要点之间的缩进层级，有对应章节的概念可以点击跳到正文；目录继续按章节顺序提供导航。图文 ZIP 中的 article.md 使用同样的导图结构。

## 完整图文 ZIP

ZIP 包含 article.md、images 目录、sources.json 和 manifest.json。正文通过相对路径引用全部正式配图，解压后可以在支持 Markdown 的本地阅读器中离线阅读。

manifest.json 记录载荷文件的字节数和 SHA256。缺少正式配图或超出资源限制时不会发布一个不完整的图文包。

## 准备与期限

下载只读取已经发布的文章，不调用模型、重新转写或重新下载原视频。离开页面不会取消已接受的导出；回到文章可以查看最近的导出状态。

成品就绪后保留 24 小时，过期后可以重新创建。单份包最多 64 MiB、128 个文件，仍受服务器当前可用磁盘和容量约束。导出过期不会删除文章。

## 私人问答

本轮两种格式只导出文章，不包含私人问答或问答中的网页补充资料。文件由当前匿名会话下载，没有默认公开分享链接。
