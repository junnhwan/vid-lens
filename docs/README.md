## 目录约定

- `architecture/`：当前系统结构、模块边界和数据流
- `decisions/`：从实现和规格中提炼的公开技术决策
- `eval/`：可复现的评测规范、配置和示例数据
- `operations/`：部署、压测和故障处理资料
- `images/`：README 和架构文档使用的图片资源

个人材料和未定稿内容放在仓库根目录的 `docs-private/`，该目录不会提交到 Git。
