# VidLens 整站摘要 UI：可交互 HTML 原型 v3

这是独立的设计评审产物。不会请求业务 API、上传文件、下载视频、调用模型、读取凭证或操作真实账号。全部视频、摘要、图、标签、问答、活动和版本为本地模拟；页面右上角一直标明边界。

完整审查与推荐方案见 [设计文档](../../design/2026-10-10-summary-ui-system-v3.md)。本目录与已有 v2 原型、另一份 UI 审查稿分开，没有覆盖它们。

## 打开

当前本机预览：[视频库](http://127.0.0.1:8902/#/library) / [阅读工作区](http://127.0.0.1:8902/#/v/agent)。服务器只绑定回环地址。

也可以直接打开 `index.html`；无构建步骤和外部依赖。本地服务停止后重启：

```sh
python3 -m http.server 8902 --bind 127.0.0.1 --directory /Users/jacob.z/misc/vid-lens/docs/prototypes/summary-ui-studio-v3
```

## 推荐体验顺序

1. 视频库：切换标签、搜索、列表/卡片；打开长文件名或无封面示例；返回时检查筛选条件。
2. 导入：先填来源与关注点，再展开高级分组；试填错误链接。提交合法链接只创建独立的模拟对象。按“下一模拟事件”检查等待→整理→文字可读→完成；事件必须手动推进，不是后台运行。
3. 阅读：章节定位、回放时间、导图节点回正文、管理标签；正文中“选段提问”或选择文字后提问。普通回答按本地固定文本播放，不改摘要。
4. 修改：第一个视频第一段支持固定差异演示。填要求→预览→关闭并重开→应用→撤销。其他段落明确提示未准备修改演示，不能应用错误内容。
5. 先保留 v1 选段和问题草稿，再应用修订：旧引用改为“查看保存快照”，不会定位新正文；发送时要求重新选择。撤销生成新版本身份。
6. 阅读正文末尾的“原型场景”可以切换配图失败、摘要失败、缺配置、断线、来源不可用、历史摘要、只读、长内容、多项局部错误。视频库可切换空库。
7. 问答页检查跨视频/知识库范围与历史会话；单视频会话回到阅读工作区。知识库检查成员与整库就绪阻断。学习笔记检查独立版本、导图/画布与证据入口。
8. 左下角切换浅色；右上角“设计原型”可重置本地演示。

检查日期：2026-10-10，Chrome；1440×900 与 1024×800。这里只列真实观察过的项目。

|---|---|
| 1440 库布局 | 六条示例行均126px高，长文件名/无封面不撑大媒体区；无全页横向溢出 |
| 阅读排版 | 正文660px、17px、31.45px行距；浅色同规格，无横向溢出 |

| 回放/提问切换 | 未发送文字与选段保留，正文阅读位置不因切换改变 |
| 刷新 | 本地问题草稿、同版本正文scrollTop（实测29.5px）、播放时间72秒可恢复；暂停播放 |
| 筛选返回 | 从 `library?tag=Agent` 进入视频，再点面包屑，回到相同筛选URL |
| 修订 | 预览刷新后保留；应用v2正文改变，v1引用改保存快照；撤销v3还原文本，身份仍为新版本 |
| 普通问答 | 本地分段输出与停止入口可用；正文保持v3，不进入修订 |
| 状态推进 | 等待/整理时无文档；文字发布后开放阅读，补图继续；完成后入口/状态位保留；不展示虚构百分比 |
| 边界场景 | 历史摘要回放定位按钮为0；只读禁用修改；长正文/多标签无横向溢出；来源失败保留正文；多错聚合“2项未完成” |

| 键盘深链 | `pane=ask`直接刷新保持提问；Esc关闭助手并清除pane参数；跳到正文不破坏路由 |
| 应用日志 | 收尾读取原型 error/warn 日志为空；不覆盖业务应用日志或网络验收 |
| 视图与主题 | ArrowRight从摘要切导图；浅色阅读实测；知识库成员/笔记入口已打开检查 |

## 能力和验证缺口

- 原型的本机持久化是设计演示；真实摘要目前仍是内存临时态，不能据此声称刷新续接已接入。原型存储也没有真实账号、media revision、digest或服务端CAS。
- 原型只存文件名/大小，不保存文件字节；没有真实上传保护、网络错误或续传测试。字幕优先、分P解析、费用、来源真实性由实际服务验收。
- 全局动态是模拟结果展示；真实接口需要汇总任务、generation与笔记run。断线按钮只切换场景，未测试真实事件恢复。
- 图全部为自制SVG示意图，不能证明真实截图找到；导图是示例章节结构；回答/差异不由模型生成。
- 知识库创建/成员写入、笔记生成/编辑/自由画布、检索诊断没有模拟成功保存，点击会说明边界。真实能力和数据模型按配套报告保留。
- 旧链接兼容、列表滚动锚点、跨设备草稿、任意历史摘要浏览、冲突完整恢复属于方案规则，未全部在这个独立HTML实现。
- 原型实测证明布局和交互可评审，不能替代真实首次导入、生成质量、只读账号权限与生产验收。

本轮仅新增设计文档、此独立原型及截图。没有修改业务代码，没有提交、推送或部署。
