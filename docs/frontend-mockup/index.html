VidLens（映知）前端 Mockup

静态线框图 · Tailwind CDN · 占位数据 · 无 API 逻辑。确认布局后进入实现阶段。

1. 视频库 library.html → /

左筛选栏 + 任务行式列表 + 右侧详情面板。含状态变体：Pending/Queued/Running/Completed/Failed/Dead、上传 Modal、空态、加载骨架。
2. 单视频问答 chat.html → /chat/:taskId

消息流 720px 限宽。流式打字、[Cx] 引用徽标、展开/收起引用卡片、strict_rag fail-closed 提示、TopK 控件。
3. 知识库问答 kb.html → /kb/:kbId

左侧成员视频栏 + 复用问答布局。引用卡片标注来源视频。含成员管理入口。
4. AI Profile 设置 settings.html → /settings

ASR/LLM/Embedding 三类 tab，列表 + 编辑表单，测试连通内联结果、设为默认、探测 embedding 维度。

状态色约定：Pending=zinc · Queued=sky · Running=amber(脉冲) · Completed=emerald · Failed=rose · Dead=zinc 实心

主色 Indigo-600 仅用于主按钮/激活态/链接；语义色 success/warning/error 集中在 Tailwind token。
